## 六、核心结论

### 6.1 需要扩展吗？

**必须扩展。** 原因：

| | 只做 "bg remover" | 扩展到完整词库 |
|---|---|---|
| 可触达流量池 | ~12K/月 | **500K-1M+/月** |
| 非品牌词 | 2,510/月 | **50K-200K/月** |
| 内容页数量 | 10-15 页 | **50-100+ 页** |
| 覆盖用户场景 | 11 个工具教程 | **30+ 场景** |

### 6.2 最大的蓝海机会

**不是 "bg remover" 的变体，而是全新场景词：**

1. 🏆 **signature background remover**（签名去背景）— 极少竞品，高频需求
2. 🏆 **passport photo background**（证件照背景）— 刚需，复购率高
3. 🏆 **product photo background**（产品图背景）— 电商，付费意愿强
4. 🏆 **background removal api**（API）— 开发者，替换成本高
5. 🏆 **stamp/receipt/certificate remover**（印章/收据/证书）— 细分蓝海

### 6.3 扩展优先级

```
第一优先：场景衍生词（signature/passport/product/logo）
  → 新流量池，竞争低，转化高

第二优先：词根变体（background remover/remove background/transparent）
  → 流量巨大但竞争也大，等权重积累后再攻

第三优先：格式+质量修饰词（png/jpg/hd/batch）
  → 长尾流量，工具页矩阵

第四优先：开发者词（api/rembg/python）
  → API 产品的流量入口
```
